# hexbot

Telegram-бот: по координатам начальной соты (широта, долгота) и числу
"кругов" рассчитывает координаты сот шестиугольной сетки вокруг и присылает
их по одной в формате:

```
(2) 015- 59.711182,27.123757
```

где в скобках — номер круга (уровня), дальше — порядковый номер соты и её
координаты.

Максимум — 10 кругов. Самый внешний круг обрезается по окружности: соты,
которые выступают за пределы круга (радиус — по самой удалённой соте
предпоследнего круга), в выдачу не попадают, но их номер не занимается
следующей сотой.

## Требования

- Docker и Docker Compose
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather)

## Запуск

1. Склонировать репозиторий:

   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd hexagon
   ```

2. Создать файл `.env` рядом с `docker-compose.yml`:

   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   ```

3. Собрать и запустить контейнер:

   ```bash
   docker compose up -d --build
   ```

4. Проверить логи (в них должно быть `Application started`):

   ```bash
   docker compose logs -f
   ```

5. Написать боту `/start` в Telegram.

## Обновление после изменений в коде

```bash
docker compose up -d --build
```

## Остановка

```bash
docker compose down
```

## Формат сообщения боту

```
широта,долгота [число_кругов]
```

Примеры:

```
59.711182,27.123757
59.711182,27.123757 5
```

Если число кругов не указано — используется значение по умолчанию (2).
Допустимый диапазон — от 0 до 10.
